# Aervox ✈️
**Fly. Manage. Build. Your aviation world.**

Aervox is a companion application for Microsoft Flight Simulator (MSFS) designed to enhance your virtual airline experience with live maps, ACARS logging, flight debriefs, and more.

## Features
* Live Map & VATSIM Traffic integration
* Automatic ACARS flight logging (SimConnect)
* Detailed flight debriefs with altitude profiles and landing rate analysis
* SimBrief integration
* Multi-language support and dark mode

## Installation
1. Go to the **Releases** page.
2. Download the latest `.msi` or `.exe` installer.
3. Run the installer and launch Aervox.
